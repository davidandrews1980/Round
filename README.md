# Round

The real Round Table app.

Open talk, a project you can finish, or both. You bring the API keys. Each seat has a job title, job instructions, personality instructions, and sliders. There is an idea board, a step-out, notes between seats, and an MCP hookup for a server that actually speaks MCP.

This is not a static page. Nothing here is pre-written for the models.

```
npm install
npm run dev
```

The app listens on port 8080. Netlify is not part of this repo.
